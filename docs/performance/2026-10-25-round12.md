# Reusing model-name collation, twelfth round

Measured on 2026-10-25 against Ruimte `5efde983e` and ADE CORE `2f1ae02c`, with Bun 1.4.2, macOS 27.2 and an Apple M4 Max. [Raw samples](2026-10-25-round12.json) include three fresh headless Chromium profiles per version and nine timed sorts per profile. Each sort orders 700 model records across 13 vendors, with missing vendors mixed in. Canvas rendering is excluded.

## Retained change

The model picker passed collation options to `localeCompare` for every comparator call. It now gets the vendor and model comparators once per sort. The shared formatting package caches each `Intl.Collator` behind a stable options object. Construction remains lazy.

The new `nameCollator(options)` preserves the runtime locale used by the previous implementation. It leaves the existing interface-language `labelCollator` and file-name ordering alone. Vendor names remain case-insensitive and lexical; model names remain case-insensitive and numeric. Missing vendors sort last, and equivalent names retain source order.

| Measurement | Before | After |
| --- | ---: | ---: |
| Chromium median, 27 sorts per version | 11.40 ms | 0.40 ms |
| Bun median, nine sorts per version | 5.89 ms | 0.42 ms |

These are model-sort CPU measurements, not timings for opening the entire picker. The final browser batch ran without competing tests or builds. Earlier exploratory after samples are excluded because export tests may have overlapped.

## Validation

Each probe compares the complete output order with the original comparator and checks that the input catalog is unchanged. Unit tests cover case ties, numeric and leading-zero names, missing vendors, stable source order, cached formatter identity and an interface-language change. Existing number, date, label and file-tree formatting tests remain unchanged. The public export snapshot gains exactly one entry, `nameCollator`.

A separate 3 ms Bun timing budget fails on the previous implementation and passes after the change. The full application check, 10,443 tests and client/desktop build pass. ADE CORE's full build, check, documentation build and tests also pass.

## Reproduce

```sh
bun --conditions=source apps/client/testing/performance/model-sort-browser.ts
BENCH_MAX_SORT_MS=3 bun --conditions=source apps/client/testing/performance/model-sort.ts
```

Set `BENCH_MODEL_SORT_SOURCE` to a saved previous `picker-entries.ts` to run the browser control and current version in the same invocation. Run timing probes separately from builds and tests.
